# 🎧 → ⌨️ Acoustic Keystroke Recovery — Live Demo

Type a word and watch a trained neural network recover it from the **sound** of
the keys being typed. No microphone needed — the app synthesises the typing audio,
then the real model reads the text back from the audio alone.

A reproduction of **Harrison et al., IEEE EuroS&PW 2023**. For **authorised,
ethical, educational use only** — only ever record your own typing or audio from
people who have given consent.

Full code and write-up: https://github.com/ALLaNRoY-TECH/Acoustic-keystroke-project
